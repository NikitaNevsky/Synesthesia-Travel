# Synesthesia Travel — лендинг

Сайт изначально выгружен из Tilda одним минифицированным `index.html` (~380 КБ, всё в 44 строки,
все ресурсы на `tildacdn.com`). Здесь он приведён в читаемую структуру и **полностью отвязан от Тильды**:
все фото, иконки, шрифты и фреймворк скачаны локально. Визуально сайт не изменился.

## Структура

```
index.html              ← страница (HTML причёсан, читается; подключает локальные ресурсы)
README.md

assets/
  images/   (60)        ← все фото и PNG (оригиналы + превью thb/optim — как использовал Tilda)
  icons/    (7)         ← SVG-иконки (5 органов чувств, капля, вопрос)
  fonts/    (7)         ← шрифт OrchideaPro (Light…Black), .woff

css/
  page.css              ← собственные стили страницы (вынесены из инлайнов, причёсаны)
  blocks-page.css       ← скомпилированные Тильдой стили блоков (причёсаны)

js/
  blocks-page.js        ← скомпилированный Тильдой JS блоков страницы

vendor/
  tilda/    (26)        ← фреймворк Тильды как есть: jQuery, hammer, tilda-*.js / tilda-*.css
                          (не редактируем — это служебный код)

_original/
  index.original.html   ← резервная копия исходной выгрузки Тильды (на всякий случай)
```

## Что было сделано

- **Все ресурсы локально.** 60 изображений, 7 иконок, 7 шрифтов и весь фреймворк Тильды
  (CSS/JS) скачаны в папки; все ссылки в HTML/CSS/JS переписаны на локальные пути.
  Сайт работает офлайн, не зависит от `tildacdn.com`.
- **Удалено лишнее:** Яндекс.Метрика (счётчик + пиксель) и мусорный скрипт браузерного
  расширения (`chrome-extension://…`), попавший при сохранении страницы.
- **Читаемость:** минифицированный HTML и собственные стили развёрнуты с отступами.
  Служебный код фреймворка Тильды оставлен как есть (его читаемым не сделать).

## Особенности (важно при доработке по ТЗ)

- Страница построена на **блоках Тильды** (`#rec…`, `data-record-type`). Внутри `index.html`
  остались небольшие инлайн-скрипты инициализации Тильды (`t_onReady`, `t_onFuncLoad`) —
  их **нельзя выносить**, они должны выполняться на месте.
- Стили блоков лежат в `css/blocks-page.css`, общие/кастомные — в `css/page.css`.
- **Бэкенд формы не настроен** (Tilda отправляла на `forms.tildacdn.com`) — отправка заявок
  пока работать не будет, это отдельная задача.
